# Foodie

Foodie is a cross-platform recipe app built with Expo and React Native. Browse a feed of meal ideas, search recipes by name or ingredient, read step-by-step cooking instructions, save favorites, and add recipes from your own kitchen.

## Get started

Install dependencies and start the Expo development server:

```bash
npm install
npx expo start
```

## Features

- Home feed with recipe categories, a featured pick, and popular recipes
- Discover recipes by category, name, or ingredient
- Recipe details with preparation time, servings, ingredients, and instructions
- Save and remove favorite recipes
- Create and browse your own recipes

Your own recipes and saved favorites are stored locally on the device or browser and remain available after restarting the app.
